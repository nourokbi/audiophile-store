# Audiophile shop

The React client of the Audiophile store: browse products, keep a cart on the server, check out with card
(Fawaterak) or cash on delivery, and follow or cancel your orders.

```bash
npm install
npm run dev     # http://localhost:5173, the API must run on port 5040
```

Built with React 18, Vite, Tailwind CSS and Lucide icons. The design comes from a Google Stitch project and
started from the Frontend Mentor Audiophile challenge.

Structure, data flow and the design tokens are described in [`../docs/frontend.md`](../docs/frontend.md).
